# 人物档案（dossier）

给「只认识四五个人、分散在几个群和私聊里」的场景用。每人一份 Markdown 档案，每轮**全部**注入（不检索就不会漏），每天凌晨自动整理一次。原有的短期记忆、摘要、memory-v3、永久记忆、熟识度/好感度全部照旧，档案是叠加的一层。

## 谁有档案

主人（`qq.json` 的 `ownerQq`）+「永久记忆」名单里的 QQ 号（设置页里的重要的人 / `settings.json` 的 `permanent.people`）。名单外的人不建档，模型输出里出现名单外的 QQ 也会被丢弃。

## 文件在哪

`$DSH_HOME/dsh-qq-group/dossier/`（Windows 默认 `%USERPROFILE%\.dsh\dsh-qq-group\dossier\`）

| 路径 | 内容 |
|---|---|
| `people/<QQ>.md` | 每人一份档案，按「## 群 群号」「## 私聊」分小节 |
| `contexts/群-<群号>.md` | 这个群的关系、群梗、她答应过的事 |
| `contexts/私聊-<QQ>.md` | 这段私聊里她答应过的事 |
| `archive/<会话>/<日期>.jsonl` | 原文存档（只追加；夜间整理读它） |
| `config.json` | 可选配置，见下 |
| `state.json` | 整理进度（自动维护，别手改） |

档案示例：

```markdown
# 小王
## 群 111111
- [身份] 程序员，在杭州 · 2026-10-28
- [和她] 爱叫她大肥鱼
## 私聊
- [感情] 刚分手，别在群里提 · 2026-10-30
## 备注
这一节不认识，原样保留、不注入（可以写给自己看的笔记）
```

- `[方面]` 是 key：同一方面有新说法会覆盖旧的；
- 末尾 `· 日期` 表示自动写入；**手写时不写日期，这条就永远不会被自动淘汰**；
- 直接用记事本改，保存后下一条消息就生效。

## 隐私规则

| 学到的地方 | 写进哪 | 在哪里会被用到 |
|---|---|---|
| 和小王的私聊 | 小王档案的「## 私聊」 | 只有和小王的私聊 |
| 群 A | 档案的「## 群 A」+ 群 A 的会话文件 | 群 A；以及当事人自己的私聊（可关） |

夜间整理按会话逐个进行，整理群 A 时交给模型的只有群 A 的原文和群 A 的小节，看不到别的群和任何私聊，所以模型也写不出别处的内容。

## 什么时候整理

- 每天 `hour` 点（默认 4 点）之后自动跑一次；那时电脑关着就开机后补跑；
- 主人私聊她发「整理档案」可以马上跑；
- 失败不会丢进度，当天最多重试 3 次，第二天从断点接着来。
- 成本：每个有新消息的会话每天调用 1 次模型（原文超过 2 万字分批）。

## config.json（都可省略）

```json
{
  "enabled": true,
  "hour": 4,
  "maxFactsPerScope": 15,
  "maxFactChars": 80,
  "injectChars": 3000,
  "groupFactsInPrivate": true,
  "chunkChars": 20000,
  "gitCommit": true,
  "archiveDays": 0
}
```

- `groupFactsInPrivate`：群里学到的关于某人的事，能不能在他自己的私聊里提。设成 `false` 就只用私聊小节。
- `gitCommit`：在 `dossier` 目录里执行一次 `git init`，之后每次整理有改动都会自动提交，改坏了可以回滚。
- `archiveDays`：原文存档保留天数，0 = 永久（过期文件改名为 `.expired`，不直接删）。
